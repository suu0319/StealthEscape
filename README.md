# StealthEscape
## Platform
Android

## Intro
Third-person sneak escape game, avoid enemies and traps to reach the end!

## Control    
```  
Left Joystick: Control Character
Right Attack Button: Attack
Top-Right Pause Button: Pause
Swipe on Empty Area: Rotate Camera
```  

## Skills  
- Unity API
- UGUI
- Animation、Animator
- Coroutine
- NavMesh
- SpriteAtlas
- EditorWindow
- ScriptableObject
- LogViewer
- DoTween
- URP
- Json

## Design Pattern
- Singleton
- Factory
- Observer
- Mediator
- Object Pool
